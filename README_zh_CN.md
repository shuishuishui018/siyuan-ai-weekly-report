# AI 周报生成器（思源笔记插件）

把零散的每日工作日志，一键汇总成结构化的周报文档。

插件会读取你在一段时间内写过的笔记，交给兼容 OpenAI 协议的大模型汇总，然后在思源里直接生成一篇新的周报文档。

## 功能

- **自动收集素材**：按文档最后更新时间筛选，可限定笔记本与路径（例如 `/工作日志`、`/每日待办`）。
- **自动跳过敏感文档**：路径命中排除关键词（默认 `账号密码`、`密码`、`密钥`、`token`、`secret`）的文档不会被读取，也不会发送给模型。
- **提取未完成任务**：素材里的 `- [ ] 跟进外部单位回函@11-25` 会被汇总成任务清单，进入「进行中」或「下周计划」，不会漏掉。
- **结构化输出**：默认「本周完成 / 进行中 / 问题与风险 / 下周计划」，系统提示词与输出结构都可以自己改。
- **兼容任意 OpenAI 协议接口**：DeepSeek、OpenAI、通义千问、Kimi、智谱、硅基流动、Ollama、LM Studio 均可。请求走思源内核转发，不受浏览器跨域限制。
- **灵活的时间区间**：本周、上周、最近 N 天、自定义起止日期。

## 安装

### 从集市安装

思源「设置 → 集市 → 插件」，搜索「AI 周报生成器」，安装并启用。

### 手动安装

1. 从 [最新发布](../../releases/latest) 下载 `package.zip`。
2. 解压到 `{工作空间}/data/plugins/siyuan-ai-weekly-report/`，确保 `plugin.json` 直接位于该目录下。
3. 重启思源，或在「设置 → 集市 → 已下载」中点击重载。

## 配置

打开「设置 → AI 周报生成器」，或执行命令「AI 周报生成器设置」。

| 配置项 | 说明 |
| --- | --- |
| API 地址 | `https://api.deepseek.com/v1`、`https://api.openai.com/v1`、`http://127.0.0.1:11434/v1` 等 |
| API Key | 只保存在插件本地数据中，不上传。使用本地模型可留空 |
| 模型名称 | `deepseek-chat`、`gpt-4o-mini`、`qwen2.5:14b` 等 |
| 包含路径 | 每行一个，按路径模糊匹配。`/工作日志` 可匹配 `/工作日志/2026年/11月/17日周会记录` |
| 排除关键词 | 路径命中的文档直接跳过。建议保留账号密码、密钥类词汇 |
| 统计方式 | 本周 / 上一周 / 最近 N 天 / 自定义区间 |

点击顶栏图标，或执行命令「生成 AI 周报」，即可生成。文档默认创建在 `/AI周报` 目录下，标题形如 `2026-W47 工作周报`，生成后自动打开。

## 素材是怎么组织的

每篇素材会被拼成：

```
### /工作日志/2026年/11月/17日周会记录（更新于 2026-11-17）
<去掉 YAML frontmatter 后的正文>
```

单篇有字数上限，全部素材也有总字数上限；超出总上限后，较早的文档会被丢弃。

## 隐私说明

- API Key 保存在本机插件的 `data/storage/petal` 目录，不会上传。
- 素材正文只会发送到你自己配置的 API 接口。
- 命中排除关键词的文档在读取之前就被过滤，不会参与本次生成。首次使用前请确认排除列表是否覆盖了你的隐私文档。

## 开发

```bash
npm install
npm run dev      # 监听编译到 dist/
npm run build    # tsc 检查 + vite 构建 + 生成 package.zip
node scripts/run-smoke.mjs   # 端到端冒烟测试（需要思源正在运行）
```

需要在真实思源中调试时，把构建出的 `index.js`、`plugin.json`、`index.css`、`i18n/` 放到 `{工作空间}/data/plugins/siyuan-ai-weekly-report/`。
